Q. How do I get SPyder to work with my existing pkgs/env?
Finally, connect Spyder to this my-env environment by changing Spyder’s default Python interpreter, following the instructions in the above answer.
https://docs.spyder-ide.org/5/faq.html#using-existing-environment

To work with an existing environment in Spyder, change the default Python interpreter for new IPython Consoles to point to this environment.

To do so, open the Python interpreter section of Spyder’s preferences (Tools ‣ Preferences, or Spyder ‣ Preferences on macOS). Here, select the option Use the following Python interpreter, and use the dropdown below to select your preferred environment. If it’s not listed, see the note below.

------ Run Spyder outside of Anaconda w/ (internal) python spyder  ----------

*	just open spyder at command line
	$ spyder


------ Run Spyder in (base) Anaconda w/o (internal) python spyder----------
*	Update Anaconda and Spyder---
	$ conda activate base
	(base) $ conda update spyder
	(base) $ conda list spyder
		# packages in environment at /home/bmarron/anaconda3:
		# Name                     Version          Build               Channel
		pyls-spyder                0.4.0            pyhd3eb1b0_0

	(base) $ spyder
			[will open spyder w/ internal python or whichever was the last setting in "wrench"]

*	In Spyder under "wrench" change Python interpreter to (base) python [clic 'Apply' and 'OK']

---- Create new Anaconda environment and Run Spyder in the new env -------

*	Create a new environment with a specific Python version: 
		$ conda create --name spyder_env		<== defualt Python will be most recent Anaconda python 
													available unless stated

		For Anaconda3 or Miniconda3 installers: The default Python version in new environments (if not 
		explicitly specified) is typically Python 3.x, where 'x' is the version that was current at the 
		time of the installer's release.

*	Activate an environment:
    	$ conda activate spyder_env


*	Install pkgs in spyder_env (spyder-kernels, :
		(spyder_env) $ conda install spyder-kernels			<== will install LOTS of pkgs

			environment location: /home/bmarron/anaconda3/envs/spyder_env
