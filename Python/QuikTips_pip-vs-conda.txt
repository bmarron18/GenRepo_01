	# another pip install mechanism
$ pip install --user <pkg>
pip install --user nltk

command is a practical solution for managing Python packages in your personal setup. It lets you avoid needing admin permissions, keeps installations separate from the system, and works especially well in shared environments where system-wide installs can cause problems.

--- file system hierarchy

* System-wide packages (installed by package managers like apt or yum)
	/usr/lib$ ls
		python2.7
		python3
			[MANY files and directories]
		python3.10
			[many .py files]
		python3.11
			[distutils  lib2to3  lib-dynload]
		python3.8
			[MANY files and directories]

* Other possible areas of installation
	/usr/local/lib$ ls
		python2.7  python3.10  python3.8  R
	/usr/local/lib/python3.10/dist-packages$ ls
		[none]
	/usr/local/lib/python3.8/dist-packages$ ls
		[none]


* User-specific packages (installed without sudo):
    ~/.local/lib/pythonX.Y/site-packages/ (where ~ represents the user's home directory)

	~/.local/lib$ ls
		python3.10
	~/.local/lib/python3.10/site-packages$ ls
		[MANY files and Directories]
